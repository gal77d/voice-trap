# ✍️ הכתב שלי – כתב יד לפונט

אפליקציית web שהופכת את כתב היד שלכם ל"פונט": מדפיסים תבנית, כותבים, מצלמים, ואז מקלידים טקסט בעברית או באנגלית ומקבלים דף בכתב היד שלכם (PNG / PDF).

- HTML + JavaScript בלבד, בלי ספריות, בלי שרת ובלי תשלום.
- כל העיבוד נעשה בדפדפן. התמונות לא נשלחות לשום מקום.
- האותיות נשמרות בזיכרון של הדפדפן במכשיר (אפשר לגבות לקובץ JSON).

## מבנה התיקייה

```
handwriting-font/
├── index.html            3 מסכים: תבנית · סריקה · כתיבה
├── css/style.css         עיצוב מותאם לטלפון, RTL, הדפסה
└── js/
    ├── config.js         רשימת התווים ומידות התבנית (מ"מ)
    ├── imageproc.js      גווני אפור, Otsu, רכיבים קשירים, הומוגרפיה, יישור, תיקון תאורה
    ├── template.js       ציור התבנית להדפסה
    ├── corner-editor.js  גרירת 4 פינות + זכוכית מגדלת + תצוגת רשת
    ├── scanner.js        זיהוי הריבועים והכיוון, יישור, חיתוך משבצות, ניקוי רקע
    ├── glyph-store.js    שמירת האותיות (localStorage), גיבוי ושחזור
    ├── composer.js       סידור הטקסט: RTL/LTR, אותיות סופיות, וריאציה טבעית
    ├── pdf.js            כותב PDF מינימלי (בלי ספריות)
    ├── util.js           הורדה, שיתוף, הודעות
    └── app.js            חיבור הממשק
```

## הפעלה בטלפון דרך GitHub Pages (מומלץ)

1. ב-GitHub פתחו את המאגר ← **Settings** ← **Pages**.
2. תחת **Build and deployment** בחרו **Source: Deploy from a branch**.
3. בחרו את הענף (למשל `main` אחרי מיזוג, או את הענף שבו נמצא הקוד) ואת התיקייה `/ (root)`, ולחצו **Save**.
4. אחרי דקה-שתיים האתר זמין בכתובת:
   `https://<שם-המשתמש>.github.io/voice-trap/handwriting-font/`
5. פתחו את הכתובת בטלפון. מומלץ: בתפריט הדפדפן ← **הוספה למסך הבית**, וכך היא תיפתח כמו אפליקציה.

## פתיחה ישירה של הקובץ

- **מחשב:** לחיצה כפולה על `index.html`. הכל עובד.
- **אנדרואיד:** העתיקו את כל התיקייה `handwriting-font` לטלפון ופתחו את `index.html` ב-Chrome דרך מנהל הקבצים.
- **אייפון:** iOS לא מריץ קבצי HTML מקומיים בצורה נוחה, ולכן עדיף GitHub Pages.

## שימוש

1. **תבנית:** מורידים PDF ומדפיסים בגודל 100%. כותבים כל תו במשבצת שלו בעט כהה.
2. **סריקה:** מצלמים את הדף מלמעלה באור טוב. האפליקציה מזהה את 4 הריבועים השחורים, ואם צריך, גוררים את העיגולים לפינות הרשת. לוחצים „חיתוך האותיות", מכוונים את סליידר הרגישות ושומרים.
3. **כתיבה:** מקלידים טקסט, מכוונים גודל, מרווחים, צבע וסוג דף, ומורידים PNG או PDF.

אפשר לסרוק שוב רק חלק מהאותיות: משבצות ריקות לא דורסות אותיות שכבר נשמרו.
